# Provenance and rights

## Files in this staging repository

The runnable repository contains source text only: HTML, CSS, JavaScript, Markdown and JSON. It contains no bundled video, audio, bitmap image, font, model weight, production database or third-party library.

The six activity concepts and interaction patterns are derived from material owned by the project. This release was written as a reduced, account-free and media-free reference. Sleeping Dragon's deterministic transition/crossing logic is retained while its visual is newly implemented with CSS-native shapes and contains no copied production media. The geometric reference scenes in Describe & Draw are original SVG source embedded in `activities/describe-draw.js`.

The owner has confirmed authority to license the included code and content for public release. Software is released under MIT; original documentation, prompts and pedagogical text are released under CC BY 4.0. The split and exclusions are defined in the root `LICENSE`, `LICENSE-CONTENT.md` and `NOTICE.md` files.

## Material not copied into the open bundle

Production video, audio, bitmap art, fonts, model files, account integrations and commercial-platform code were reviewed only to define scope and were not copied into this repository. No private archive name, internal path, checksum or production identifier is published here. Exclusion is intentional: the open package contains only material the owner approved for this release.

## Required record for future assets

For every added asset, record:

- exact filename and checksum;
- creator and rights holder;
- creation date and source tool;
- input/reference rights where applicable;
- licence and redistribution permission;
- required attribution;
- whether people, voices, trademarks or sensitive data appear; and
- reviewer and approval date.

Do not add an asset until every required field is complete. A future asset's own documented licence must be compatible with the repository and must not be inferred from the licences covering current source and text.
